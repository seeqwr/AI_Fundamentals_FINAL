03 / THE BEHAVIORAL SYSTEMS

UNDERSTAND THE ALGORITHMS

LEVEL GENERATION

CSP — Неделя 3

Лабиринт генерируется с соблюдением системы ограничений: путь [Старт → Ключ → Выход] гарантированно существует, ключ незаблокирован, а монстр стартует на безопасном расстоянии.

Constraint Satisfaction Problem

MONSTER HEARING

HMM — Неделя 7

Каждый шаг по шумным плиткам вызывает акустический сигнал. Скрытая Марковская Модель пересчитывает матрицу апостериорных вероятностей (Belief Distribution), направляя патруль к источнику шума.

Hidden Markov Model

PURSUIT

A* — Неделя 2

Луч Брезенхэма проверяет видимость: стены прерывают погоню. A* ведёт к видимой цели, последней известной позиции или источнику шума. Сталкер прогнозирует движение на два шага; слепой брут ориентируется только по акустическим наблюдениям HMM.

A-Star Pathfinding
