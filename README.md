# The Quiet Grid

The Quiet Grid — күзетші роботтарға байқалмай, шығаберіске жетуді көздейтін браузер ойыны. Кездейсоқ секторда алты кристалл жинайсың. Кездейсоқ лабиринтте кейіпкердің көзімен дәліздерді аралап, шығаберістің кілтін іздейсің. Робот қадамыңды естиді, көзіне түссең, ізіңе түседі.

## Іске қосу

1. Жоба қалтасында PowerShell немесе терминал аш.
2. Жергілікті серверді іске қос.

   ```powershell
   python server.py
   ```

3. Браузерде [ойын бетін](http://localhost:5000) аш. **«Секторға кіру»** түймесі экранда тұрған картамен ойынды бастайды. Басқа режимді таңдау үшін **«Баптаулар» → «Ойын режимі»** бөліміне кір.

Сервер Python 3-тің стандартты кітапханасымен жұмыс істейді. Ойынды тек браузерде іске қосу үшін `index.html` файлын тікелей ашуға болады. Сервер қолжетімсіз болса, кездейсоқ лабиринттің ережелерін браузердегі JavaScript қозғалтқышы орындайды. Сектор мен қадамдық тапсырмалар әр қойындыда дербес орындалады. Python сервері кездейсоқ лабиринттің бір ортақ ойын күйін сақтайды, сондықтан басқа қойындыда жаңа лабиринт бастасаң, сервердегі ойын да жаңарады.

## Ойын режимдері

### Кездейсоқ сектор

Екі бөлмедегі үш-үш кристалдың бәрін жинап, түсі өзгерген порталға жет. Үш күзетші сен тоқтап тұрсаң да қозғалады. Мәзірді ашқанда немесе басқа қойындыға ауысқанда сектор кідіреді.

**«Жаңа кездейсоқ сектор»** үш жоспардың бірін және басқа безендіруді таңдайды. Бөлмелердің орналасу бағыты, тасалар, металл торлар және патрульдердің бастапқы нүктелері өзгереді. «Реле торабын» жасыл жолақтар мен жұп тіректерінен, «Жылу алмастырғышты» мыс түсті қырларынан, «Криокамераны» көгілдір сақиналары мен дөңгелек модульдерінен тануға болады. **«Қайта бастау»** сол секторды бастапқы күйіне қайтарады.

Күзетші кейде тоқтап, ашық өткелдерді шолып шығады. Алдындағы жолақты конус оның қайда қарап тұрғанын көрсетеді. Қабырға көріністі бөгейді. Күзетші дыбыс естісе, дыбыс шыққан жерге барады, ал сені көрсе, қуады. Бір торкөздік тар дәлізде қарсы келген күзетшілер жақын тармаққа шегініп, бір-біріне жол бере алады.

| Сектордағы дыбыс | Күзетшінің есту қашықтығы |
| --- | --- |
| Кәдімгі қадам | 4 торкөз |
| Металл тор үстіндегі қадам | 8 торкөз |
| Сынған құты | 12 торкөз |
| Shift басып жүріп өткен қадам | Торлы еденде де дыбыссыз |

### Кездейсоқ лабиринт

Кілтті тауып, шығаберіске жет. 3D камера дәлізді кейіпкердің көзімен көрсетеді. Робот кездейсоқ жерден бастайды. Жаңа лабиринтте шағын карта ашық тұрады және қызыл нүкте роботтың орнын кез келген қашықтықтан, тіпті зерттелмеген аймақта да көрсетеді. **«Робот»** түймесі сол белгіні шағын картада да, 2D көріністе де жасырады немесе қайта көрсетеді.

Кейіпкер еркін қозғалады. Басқа торкөзге өткенде, құты лақтырғанда немесе бір жүріс күткенде робот әрекет етеді. Камераны бұруға жүріс жұмсалмайды. Баптаулардан лабиринттің өлшемін, қарсылас түрін, көру және есту қашықтығын таңдауға болады. Бұл мәндер келесі ойында қолданылады.

| Қарсылас | Әрекеті |
| --- | --- |
| Аңшы | Ойыншыны көргенде A* алгоритмімен оған жететін жолды табады. |
| Ізкесер | Қатарынан екі рет көрген ойыншының бағытына қарап, екі торкөз алдағы орнын болжайды. Екі торкөздей аралық ұстап, ойыншы жақындаса, оны ұстай алады. |
| Соқыр дәу | Көру қашықтығы нөлге тең. Таңдалған есту қашықтығынан төрт торкөз алысырақ естиді. Дыбыс пен есте қалған орынға сүйеніп іздейді. |

### Қадамдық тапсырмалар

Мәзірде қолмен жасалған үш деңгей бар. «Көз алдында» деңгейінде бір, «Қос патрульде» екі, «Тыныш торапта» үш күзетші жүреді. Әрекет жасаған сайын патруль де бір жүріс жасайды. Кілтті алып, порталға жету үшін күзетшінің бұрылғанын күтуге болады.

Күзетшінің көру бұрышы — 90°, көру қашықтығы — төрт торкөз. Толық картада оның тұрған орны, көру аймағы және үзік сызықпен белгіленген бағыты көрінеді. Қуған кезде конус қызғылт сары түске өзгереді. Жай еденде дыбыссыз жүресің, торлы едендегі қадам төрт торкөзге, сынған құты сегіз торкөзге естіледі. Әр патрульдің өз нысанасы мен жады бар. Сені көзден жоғалтқан күзетші соңғы белгілі орныңды тексеріп, содан кейін бағытына оралады.

Жеңістен кейін келесі деңгейге өтуге болады. Үш деңгейдің кез келгенін мәзірден де таңдай аласың. Браузер әр деңгей жоспарының нұсқасы үшін ең аз жүріс санын сақтайды.

## Басқару, карта және дыбыс

| Басқару құралы | Әрекеті |
| --- | --- |
| **W, A, S, D** | Секторда карта бағытымен жүресің. Бірінші жақтағы лабиринтте W/S алға және артқа, A/D бүйірге жүргізеді. Екі пернені қатар бассаң, қиғаш жүресің. |
| **Shift** | Сектор мен кездейсоқ лабиринтте басып тұрсаң, кейіпкер екі есе баяу әрі дыбыссыз қозғалады. Робот көру аймағына кірген ойыншыны байқай алады. |
| **Бағыттауыш пернелер** | Секторда кейіпкерді қозғалтады. Бірінші жақтағы лабиринтте ← және → көріністі 90°-қа бұрады. |
| **Бос орын** | Кездейсоқ лабиринт пен қадамдық тапсырмада бір жүріс күтесің. |
| **E** немесе **«Құты»** | Лақтыру орнын таңдауды қосады. Көрініп тұрған жарық торкөзді бассаң, құты сол жерге түседі. E, Esc немесе «Құты» түймесін қайта басу таңдауды тоқтатады. |
| **Тінтуір немесе сенсорлық экран** | 3D көріністі сүйреп, айналаға қарайсың. Телефонда қозғалыс батырмасын басып тұрып, саусағыңды сырғыту арқылы кез келген бұрышпен жүре аласың. |
| **Камера батырмалары** | Сектор мен тапсырмада «+», «−» немесе тінтуір дөңгелегі масштабты өзгертеді. Дөңгелек жебе камераны 90°-қа бұрады. Нысана белгісі ойыншыны қадағалауды қосады, тор белгісі жалпы көрініске қайтарады. |
| **2D / 3D** | Барлық режимде 2D картаны жоғарыдан көрсетеді. WebGL қолжетімсіз болса, ойын 2D көрінісін қолданады. Қатар тұрған карта батырмасы шағын картаны ашып-жабады. |

Сектордағы қалыпты жылдамдық — секундына 2,6 торкөз. Қиғаш жүргенде де жылдамдық осы күйде қалады. Пернелерді жіберіп, торкөздің ортасына жетпей тоқтай аласың немесе қабырға бойымен сырғып өтесің. Секторда камера бұрылғанда WASD бағыттары картаға қатысты сақталады.

Ойынды үш құтымен бастайсың. Жарамды лақтыру бір құтыны жұмсайды және бір әрекет болып есептеледі. Қабырғаны немесе көрінбейтін торкөзді таңдасаң, қорың сақталады. Күзетшімен түйіссең, ойын аяқталады.

**«Толық картаны басынан көрсету»** бастапқыда қосулы. Қабырғалар, еден, шулы торкөздер және мақсаттар бірден көрінеді. Оны өшіргенде бұрын зерттеген жерлер картада қалады. Патруль бағыттарын бөлек өшіруге болады. Толық экран батырмасы ойын алаңын бүкіл экранға жаяды.

Динамик батырмасы дыбысты қосып-өшіреді. Баптауларда дыбыс деңгейін өзгертіп, **«Тыңдап көру»** батырмасымен тексеруге болады. Дыбыс алғашқы басудан кейін қосылады, ал таңдалған деңгей браузерде сақталады. Жақын маңдағы көрінетін күзетші айналасын шолғанда бәсеңдей түсетін сигнал, дыбысқа елеңдегенде жоғарылайтын сигнал, ойыншыны байқағанда екі қысқа дабыл естіледі. Бір орында күту мен қабырғаға тірелу аяқ дыбысын шығармайды.

## Робот ойыншыны қалай іздейді?

**Көру.** Бірінші жақтан қарағанда ашық дәліздің бүкіл ұзындығы көрінеді, ал қабырға арғы жағындағы роботты тасалайды. Кездейсоқ лабиринтте жаңа жерді зерттеу және құты лақтыру ауқымы — Манхэттен қашықтығымен үш торкөз. Бұл қашықтық екі нүктенің көлденең және тік аралықтарын қосу арқылы есептеледі. Брезенхэм алгоритмі көру сызығының қабырғаға тірелуін тексереді. Қабырғаның өзі көрінеді, бірақ тұйық қиғаш бұрыштың арғы жағы көрінбейді.

**Есту және жад.** Кездейсоқ лабиринтте жай қадам қарсыластың белгіленген есту қашықтығына, ал шыны үстіндегі қадам мен сынған құты екі есе алысқа естіледі. Дыбыстың қашықтығы Манхэттен өлшемімен есептеледі, сондықтан осы модельде дыбыс қабырғадан да өтеді. Робот ести алмаған дыбыс оның нысанасын өзгертпейді.

Жасырын Марков моделі (HMM) ойыншы болуы мүмкін әр торкөзге ықтималдық береді. Әр жүрісте модель ойыншы орнында қалуы немесе көршілес еденге өтуі мүмкін деп болжап, үлестірімді жаңартады. Қадам естілсе, ол алдыңғы болжамның 20%-ын біркелкі үлестірімнің 80%-ымен араластырады. Содан кейін әр торкөздің салмағын дыбыс көзіне дейінгі қашықтыққа қарай `0.18 ** distance` көбейткішімен түзетіп, ықтималдықтардың қосындысын бірге теңестіреді. Құты сынғанда есеп біркелкі үлестірімнен қайта басталады. Дыбыс естілмесе, есептеу тыңдап тұрған роботтың орны мен есту ауқымына сүйенеді. Робот ойыншыны тікелей көрсе, модель ықтималдықты сол торкөзге жинақтайды.

**Жол табу.** A* алгоритмі таңдалған нысанаға қабырғаларды айналып өтетін жол іздейді. Роботтың негізгі күйлері — патрульдеу (`PATROL`), шолу (`SCAN`), дыбысты тексеру (`INVESTIGATE`), қуу (`CHASE`), жолын кесу (`STALK`) және іздеу (`SEARCH`). Кездейсоқ лабиринтте байланыс үзілсе, робот соңғы белгілі нысананы төрт жүріске дейін іздеп, патрульге оралады.

**Телеметрия.** Мәзірдегі **«ЖИ телеметриясы»** терезесі күзеттің күйі мен дабыл деңгейін көрсетеді. **«ЖИ болжамы»** қосқышы бірден әсер етеді. Картадағы ең жарық торкөзге модель ең жоғары ықтималдық берген. Карта ағымдағы максимумға қарай боялады, ал жазуда сол торкөздің нақты ықтималдығы беріледі. Болжам барлық еденді қамтиды, сондықтан ол зерттелмеген дәліздердің пішінін де көрсете алады.

`detection_probability` көрсеткіші ойыншы тұрған және одан бір торкөзге дейінгі орындардың ықтималдықтарын қосады. Экрандағы ең төменгі мән — 5%. Бұл көрсеткіш арқылы модель бағасын бақылауға болады. Робот нысанасын өзі көрген не естіген дерекке сүйеніп таңдайды. Ширығу графигінің түсі мен тербелісі дабыл күйіне байланысты өзгереді. Жүйеде қозғалыс әсерлерін азайту баптауы қосылса, жарықтың бүлкілдеуі мен шаң әсері өшеді.

## Сынақтарды жүргізу

Төмендегі пәрмендерді жоба қалтасында орында. Толық тексеруге Python 3 пен Node.js қажет. Python сынақтарының бір бөлігі екі қозғалтқышты салыстыру үшін Node.js-ті өзі шақырады.

```powershell
python -m unittest discover -s tests -v
node --check game.js
node --check audio.js
node --test tests/test_presentation.js tests/test_campaign.js
```

Сынақтар қабырғадан өтуді, бұрыштағы көріністі, дыбыссыз жүрісті, есту қашықтығын, құты лақтыруды және жеңіс пен жеңіліс шарттарын тексереді. Дайын тапсырмаларда бөлек жоспарлаушы күзетке байқалмай өтетін жолды тауып, сынақ сол жүрістерді ойын қозғалтқышымен қайталайды.
